# Agent graph (LangGraph)

Generated by `python -m triage graph`. `human_approval` pauses the run (interrupt) until a human answers y/N; state is checkpointed in SQLite, so a paused run resumes by thread id. `diagnose_failure` only runs when an upgrade PR's CI is failing.

```mermaid
---
config:
  flowchart:
    curve: linear
---
graph TD;
	__start__([<p>__start__</p>]):::first
	collect(collect)
	fetch_advisories(fetch_advisories)
	match(match)
	plan(plan)
	assess_upgrade_risk(assess_upgrade_risk)
	human_approval(human_approval)
	open_pr(open_pr)
	watch_ci(watch_ci)
	diagnose_failure(diagnose_failure)
	report(report)
	__end__([<p>__end__</p>]):::last
	__start__ --> collect;
	assess_upgrade_risk --> human_approval;
	collect --> fetch_advisories;
	diagnose_failure --> report;
	fetch_advisories --> match;
	human_approval --> open_pr;
	match --> plan;
	open_pr --> watch_ci;
	plan --> assess_upgrade_risk;
	watch_ci -.-> diagnose_failure;
	watch_ci -.-> report;
	report --> __end__;
	classDef default fill:#f2f0ff,line-height:1.2
	classDef first fill-opacity:0
	classDef last fill:#bfb6fc
```
